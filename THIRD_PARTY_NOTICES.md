# Third-party notices

The repository does not currently redistribute third-party binaries.

Future distributions are expected to use a native Unity bootstrap and a runtime
detour backend. Their exact versions, licenses, source locations, and required
notices must be recorded here before any release bundle is published.

Planned integrations are architectural intentions, not bundled dependencies:

- UnityDoorstop — LGPL-2.1
- MonoMod.RuntimeDetour — MIT
- HarmonyX — MIT, if adopted
- Il2CppInterop — to be evaluated for the future IL2CPP backend
